# 神蹟到貨 Miracle Delivered

桌上原始人文明的網頁小遊戲。你是坐在書桌前的神，用信仰值在虛構的網購商店下單；包裹從天而降，落進一整片迷你大地，成為原始人文明的神蹟或災難。文明的危機取材自真實歷史，從石器時代一路走到太空時代或滅亡。

目前在設計與原型階段，詳見 [HANDOFF.md](HANDOFF.md)。
